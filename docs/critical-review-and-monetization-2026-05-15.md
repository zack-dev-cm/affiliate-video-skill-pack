## What The Tutorial Gets Right

- The operational loop is strong: product research, product-specific creative, UGC video, carousel, caption/SEO, and cross-posting.
- Pinterest is a reasonable first channel for visual evergreen content, especially when a pin adds original value and is not just repetitive affiliate spam.
- Claude plus a video-generation MCP is a useful creative interface because the operator can keep strategy, prompt drafts, and asset review in one conversation.
- Carousels are a good low-cost complement to video because they can explain the problem, routine, benefit, and CTA without relying on perfect generated motion.

## What Needs Correction

- The supplement example is high-risk. Sleep, anxiety, magnesium, vitamins, skincare, weight loss, and similar categories trigger claim substantiation and platform restrictions.
- "No website needed" is strategically weak. Direct affiliate links can work, but an owned landing page gives disclosure control, analytics, retargeting, email capture, policy pages, and a fallback when social links are limited.
- "Always allow" for a paid MCP connector is too broad. Generation drafts can run in batches, but spend, sensitive claims, product rights, and publishing need review gates.
- Fake UGC is a trust risk. A generated actor should not imply personal product experience unless the operator actually has that experience and the claim is truthful.
- Generated packaging text is not reliable. Product labels, trademarks, prices, and claims must be verified from the product source before publishing.
- The daily volume formula is too blunt. Posting cadence should be tied to quality, original value, cost per asset, and kill/scale analytics.

## Skill Strategy

Create one public base skill first:

- `affiliate-video-campaign-operator`: campaign ledger, compliance checks, Claude/Higgsfield creative pack, OpenClaw publishing handoff, analytics loop.

Then combine it with existing skills:

- `agentic-video-production-publisher`: use for character consistency, music maps, complex shot ledgers, and video provenance.
- `openclaw-youtube-tiktok-publisher`: use after campaign QC for supervised YouTube/TikTok upload.
- `chrome-extension-cws-shipper`: use for a companion extension that captures product evidence, disclosures, affiliate links, and publish receipts.
- `design-md-ui-designer`: use for owned landing pages and visual conversion assets.

## Monetization

Recommended product ladder:

1. Free skill pack on GitHub and ClawHub.
2. $29-$79 compliant prompt/template pack.
3. Freemium Chrome extension for product/post receipts.
4. $299-$999 setup review.
5. $500-$2,500/month managed campaign operator.

Best first verticals:

- creator desk gear
- camera/mobile accessories
- home organization
- kitchen workflow tools
- productivity software
- AI creator tools with demonstrable features

Avoid using supplements as the flagship demo. They look attractive in tutorials but create avoidable launch risk.

## Chrome Extension Concept

Name: `Affiliate Video Receipt`

Free:

- capture product page URL, screenshot, title, merchant, price snapshot, and affiliate URL
- capture disclosure text used on each platform
- export campaign JSON for Codex/Claude/OpenClaw

Pro:

- detect missing disclosures before posting
- flag sensitive claims on product pages and captions
- attach source screenshots to campaign ledger
- track posted URLs and basic metrics imports
- export OpenClaw handoffs
