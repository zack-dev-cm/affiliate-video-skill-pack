# OpenClaw Publish Checklist

## Before Browser Automation

- Campaign QC report has no blocking errors.
- Asset path exists and matches platform format.
- Caption includes clear disclosure.
- Affiliate URL is authorized for the account/site.
- Native paid partnership/commercial labels are known.
- No credentials, cookies, or private account data are in the handoff bundle.

## Browser Run

- Capture screenshots:

  - metadata/disclosure screen
  - link/destination preview
  - final confirmation
  - public/draft URL
