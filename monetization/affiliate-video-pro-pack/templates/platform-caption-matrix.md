# Platform Caption Matrix

| Platform | Caption opening | Disclosure | Link placement | Native label | Notes |
| --- | --- | --- | --- | --- | --- |
| Pinterest |  | Paid link. | destination URL / description | paid partnership if applicable | Avoid repetitive affiliate pins. |
| TikTok |  | #ad or clear equivalent | profile / shop / allowed link | commercial content disclosure | Avoid restricted categories. |
| YouTube Shorts |  | Paid link. | description / eligible brand link | paid promotion checkbox when applicable | Put disclosure in video and description. |
| Instagram Reels |  | Paid link. | bio / story / sticker | paid partnership label when applicable | Keep disclosure before hashtags. |

## Caption Formula

1. Clear disclosure.
2. One problem or workflow moment.
3. One product role.
4. One bounded CTA.
5. Hashtags after the disclosure and message.
